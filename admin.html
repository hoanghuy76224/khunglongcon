Đăng nhập Dino Admin

Dán GitHub token để sửa trang khunglongcon.com. Mỗi thiết bị chỉ cần dán một lần.

  1. Mở trang tạo token của GitHub.
  2. Ở Repository access, chọn Only select repositories, chọn khunglongcon.
  3. Ở Permissions, mở Contents và chọn Read and write.
  4. Bấm Generate token, sao chép rồi dán xuống đây.
